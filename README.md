# SketchLib

A online repository of sketch-related research papers.

## List of Labels

Update the Labels column for the newly added papers in papers.csv. The labels can only be picked from the following list. Multiple labels are allowed for each paper. Feel free to use the labels at any level. Concatenate all suitable labels with semicolons. Find the most suitable labels based on the paper title for newly added paper and update papers.csv.
